# Island Studio — a full video editor

[**Island Studio**](https://github.com/mlecoq/react-native-video-editor) is a
complete, tutorial-grade video editor built on this library. It's the best
place to see every feature working together in real code — about 15 small,
documented files.

<p align="center">
  <img src="/react-native-skia-video/img/island-studio.gif" width="260" alt="Island Studio demo" style={{ borderRadius: 16 }} />
</p>

**What it does:** montage of up to 6 photos/videos from the gallery (or
bundled island-themed samples), SkSL shader transitions between clips,
draggable/pinchable text and image overlays with enter/exit animations,
royalty-free soundtracks looped over the montage, and a hardware-encoded
1080×1920 export saved to the photo library.

```sh
git clone https://github.com/mlecoq/react-native-video-editor
cd react-native-video-editor
npm install
npx expo prebuild
npx expo run:ios # or run:android
```

## The architecture in one diagram

```
        EditorState (plain data, geometry as canvas fractions)
                             │
                    drawFrame worklet  ★ src/editor/drawFrame.ts
              ┌──────────────┼──────────────────┐
        clips + SkSL     image overlays     text overlays
        transitions      (SkImage cache)    (paragraph cache)
              │                                  │
   ┌──────────┴───────────┐          ┌───────────┴──────────┐
   │ useVideoComposition  │          │ exportVideoComposition│
   │ Player (preview)     │          │ (background export)   │
   └──────────────────────┘          └───────────────────────┘
```

One `drawFrame` renders both the live preview and the export — the pattern
this library is designed around.

## Patterns worth stealing

**Timeline with transition overlap** — clips store durations, not start
times. An accumulator derives start times, overlapping each clip with the
previous one by the transition duration; during the overlap both clips are
active and a shader blends them
([`timeline.ts`](https://github.com/mlecoq/react-native-video-editor/blob/main/src/editor/timeline.ts)).

**Transitions as SkSL shaders** — each transition is a few lines of SkSL
receiving the two frames as child shaders and a `progress` uniform. Adding
one is copy-pasting from [gl-transitions](https://gl-transitions.com/)
([`transitions.ts`](https://github.com/mlecoq/react-native-video-editor/blob/main/src/editor/transitions.ts)).

**Gestures without React renders** — dragging an overlay writes into a
Reanimated shared value that `drawFrame` merges over the selected layer;
React state is only committed when the fingers lift
([`VideoPreview.tsx`](https://github.com/mlecoq/react-native-video-editor/blob/main/src/components/VideoPreview.tsx)).

**Resolution independence** — all overlay geometry lives in fractions of the
canvas, so the ~200pt preview and the 1080×1920 export render the exact same
composition.

**Assets across worklet runtimes** — Skia objects can't hop between
runtimes; raw `Uint8Array`s can. Images and fonts are kept as bytes and each
runtime decodes + caches its own `SkImage`s, typefaces and laid-out
paragraphs
([`skiaCache.ts`](https://github.com/mlecoq/react-native-video-editor/blob/main/src/editor/skiaCache.ts)).

**Looping music** — the soundtrack is chained `kind: 'audio'` items covering
the montage duration, mixed into the export automatically
([Audio guide](/docs/video-composition/audio)).

## Common pitfalls it solves

- **Worklet helpers must be defined before their callers** — closures are
  captured at the definition site; a helper declared further down the file is
  captured uninitialized and crashes at runtime.
- **iOS silent switch** — without a playback audio session
  (`playsInSilentMode`), compositions appear muted on device.
- **Version matrix** — the example pins the combination shipped in
  production by Azzapp: `@shopify/react-native-skia` 2.6.x, Reanimated 4.5,
  skia-video 0.10.
